Publisher Settings

Central configuration area for the Scopusixteen Publishing platform. Manage platform information, journals, publishing models, editorial workflows, notifications and service settings.

Prototype notice: This settings centre is a frontend demonstration. Changes are stored only in this browser using local storage and are not connected to a live database, authentication system, payment gateway, email server, DOI service or production publishing infrastructure.

Site Information

Basic information displayed throughout the publishing platform.

Journal Settings

Configure general journal presentation and submission options.

Enable Journal Directory Display available journals on the public website.
Allow Manuscript Submission Allow authors to access the manuscript submission interface.
Display ISSN Information Display ISSN fields where an official ISSN has been established.
Show Publishing Model Show whether a journal uses APC, subscription or hybrid publishing.

Publishing Models

Configure the publishing models that the platform can present.

APC / Open Access

Authors may be charged an Article Processing Charge where a journal officially operates under this model.


Subscription

Access may be provided through subscription plans where this model has been formally established.


Hybrid

Journals may combine subscription access with optional open-access publication routes.


APC Configuration

Demonstration settings for Article Processing Charges. These values do not create real invoices or payment requests.

APC Rules

Display APC Before Submission Show the applicable demonstration APC information before submission.
Waiver Requests Allow authors to indicate that they wish to request a waiver or discount.

AI Assistant Settings

Configure the demonstration AI assistant. A real AI provider, API credentials and secure server-side integration must be added before production use.

Enable AI Assistant Display the AI assistant interface on the platform.
Responsible AI Notice Show users a notice explaining that AI output requires human verification.
Research Assistance Allow the assistant interface to provide research-support prompts.


Never place a private AI API key directly inside frontend HTML, CSS or JavaScript. Production AI integrations should use a secure backend/server environment.
